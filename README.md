# WS09_Software_Solutions_for_Business 🏆💻

Bem-vindo(a) ao meu repositório central para a ocupação **WorldSkills Skill 09 - Software Applications Development**.

Este repositório é dedicado a armazenar TODOS os meus materiais de estudo, projetos, módulos de teste e documentações durante a minha preparação, começando primeiramente pela **Etapa Nacional** da WorldSkills.

## 🎯 Sobre a Ocupação (WS09)
O desenvolvimento de aplicações de software envolve a criação de soluções tecnológicas para negócios, estudando as necessidades de informação, fluxo de sistemas e processos de trabalho. O profissional atua desenvolvendo desde o banco de dados até as interfaces para desktop, web e mobile.

## 🛠️ Stack Tecnológico
Com base nas descrições técnicas oficiais da WorldSkills, os projetos e treinamentos contidos neste repositório utilizam as seguintes tecnologias:
* **Linguagens e Frameworks:** C# e ASP.NET (.NET Framework e Core)
* **Ambientes de Desenvolvimento (IDEs):** Visual Studio, Visual Studio Code e Android Studio
* **Bancos de Dados:** MS SQL Server e MariaDB
* **Design e Documentação:** MS Visio e Draw.io

## 📂 Estrutura Sugerida do Repositório

* 📁 `01_Banco_de_Dados/` - Scripts SQL, modelagem e importação de dados.
